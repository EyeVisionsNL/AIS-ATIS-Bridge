# AIS-ATIS Bridge field guide

Public documentation on GitHub Pages. This branch is separate from the application release branches.

Edit source/*.md or build.py, install requirements.txt, then run `python build.py` and commit generated HTML plus search.json. CSS and JavaScript are shared in style.css and app.js.

Content checked against Stable 0.1.13, main commit e2887ef5ae14257222c41257a6d421db3f79ba01. Images are pinned to that commit. The dashboard preview contains demonstration data.
